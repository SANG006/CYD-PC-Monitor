CYD PC Monitor

จอแสดงสถานะคอมพิวเตอร์ผ่าน USB • ชุดติดตั้ง 1.2.0 / เฟิร์มแวร์ 1.2

เฟิร์มแวร์ 1.2 แก้ข้อความและช่องกระพริบเวลาอัปเดต โดยเตรียมภาพก่อนส่งลงจอและวาดเฉพาะส่วนที่เปลี่ยน บอร์ดที่ใช้เฟิร์มแวร์ 1.1 ต้องอัปโหลดเฟิร์มแวร์ 1.2 หนึ่งครั้ง การติดตั้งแอปอย่างเดียวไม่เปลี่ยนโปรแกรมบนบอร์ด

เมื่อติดตั้งทับรุ่นเดิม ตัวติดตั้งจะถอน CYD PC Monitor รุ่นเดิมก่อนลงรุ่นใหม่และเก็บการตั้งค่าไว้ กรุณาปิดแอปเดิมก่อนเริ่ม หากถอนรุ่นเดิมไม่ได้ ตัวติดตั้งจะหยุดพร้อมแจ้งสาเหตุ

ค่า CPU ใช้ Windows Processor Utility ซึ่งเป็นวิธีวัดที่ Task Manager บนเครื่องที่ทดสอบใช้ ตัวเลขอาจต่างกันเล็กน้อยตามเวลาที่เก็บตัวอย่างและการปัดเศษ หาก Windows อ่านค่านี้ไม่ได้ แอปจะแสดง N/A

เริ่มใช้งานบนคอมเครื่องใหม่

  1. ต่อบอร์ด CYD ด้วยสาย USB ที่ส่งข้อมูลได้ บอร์ดที่ลง PC Monitor แล้วใช้งานได้ทันที
  2. เปิด CYD PC Monitor จากเดสก์ท็อปหรือเมนู Start
  3. กด ค้นหาพอร์ต เลือก COM ของบอร์ด แล้วกด เชื่อมต่อ หมายเลขพอร์ตอาจต่างจากคอมเครื่องเดิม
  4. เลือกค่าแต่ละช่อง เลือก 4 หรือ 6 ช่อง ปรับสีและความสว่าง แล้วกด บันทึกการตั้งค่า
แอปต้องเปิดอยู่เพื่อส่งข้อมูลไปยังบอร์ด ปุ่ม ซ่อนไว้ข้างนาฬิกา ให้ทำงานต่อในถาดระบบ ดับเบิลคลิกไอคอนเพื่อเปิดหน้าตั้งค่ากลับมา

ไม่พบพอร์ต USB

ลองสาย USB อีกเส้นและตรวจ Device Manager บอร์ด CYD รุ่นนี้ใช้ชิป CH340 หากยังไม่มีไดรเวอร์ ให้ดาวน์โหลดจาก เว็บไซต์ WCH ทางการ การติดตั้งไดรเวอร์อาจต้องใช้สิทธิ์ผู้ดูแลระบบ

ปิด Serial Monitor ของ Arduino และแอปอื่นที่ใช้พอร์ตเดียวกันก่อนเชื่อมต่อ

อุณหภูมิแสดง N/A

ค่าที่อ่านไม่ได้จะแสดง N/A ฮาร์ดแวร์บางรุ่นต้องติดตั้ง PawnIO ทางการ และเปิดแอปด้วย Run as administrator ค่าที่มีขึ้นอยู่กับ CPU/GPU ของคอมแต่ละเครื่อง ตัวติดตั้งแอปไม่ติดตั้งไดรเวอร์ USB หรือ PawnIO ให้อัตโนมัติ

บอร์ดใหม่ที่ยังไม่ได้ลง PC Monitor

สำหรับบอร์ด CYD ESP32-2432S028R ให้เลือกพอร์ต USB แล้วกด อัปโหลดเฟิร์มแวร์ ยืนยันพอร์ตและรอให้ครบ 100% ขณะอัปโหลดให้เสียบ USB ไว้ เมื่อเสร็จแอปจะเชื่อมต่อบอร์ดอีกครั้ง บอร์ดที่ลงเฟิร์มแวร์ 1.2 แล้วพร้อมใช้งาน

เปิดพร้อม Windows

เลือกพอร์ตของบอร์ดและกด บันทึกการตั้งค่า จากนั้นติ๊ก เปิดพร้อม Windows (ซ่อนไว้ข้างนาฬิกา) การเปิดหรือปิดมีผลทันทีสำหรับการลงชื่อเข้าใช้ครั้งถัดไป เปิดหน้าตั้งค่าจากไอคอนข้างนาฬิกา

ข้อมูลและการถอนติดตั้ง

แอปอ่านสถานะจากคอมแล้วส่งไปยังบอร์ดทาง USB ใช้ข้อมูลภายในเครื่อง ไม่ต้องสมัครบัญชี ตั้งค่าเก็บที่ %LOCALAPPDATA%\CYD-PC-Monitor\settings.json แยกกันบนคอมแต่ละเครื่อง

ถอนติดตั้งผ่าน Windows Settings → Apps → CYD PC Monitor ข้อมูลตั้งค่าส่วนตัวจะยังอยู่เพื่อใช้เมื่อติดตั้งใหม่

ต้องใช้ Windows 10 รุ่น 1809 ขึ้นไป หรือ Windows 11 บนคอม x64 และ .NET Framework 4.7.2 ขึ้นไป ตัวติดตั้งตรวจเงื่อนไขนี้ก่อนติดตั้ง หากขาด ให้ติดตั้งจาก Microsoft ทางการ
